# 📖 용어집 (GLOSSARY)

처음 보는 단어가 나오면 여기서 찾아보세요. 어려운 정의 대신 **비유 한 줄**로 설명합니다.

## 웹/크롤링
- **크롤링(crawling)**: 사람이 브라우저로 보던 데이터를 **코드가 대신 가져오는** 것.
- **HTTP**: 브라우저(또는 코드)와 서버가 대화하는 규칙. "요청(request)"을 보내면 "응답(response)"이 옴.
- **GET / POST**: 요청의 종류. GET="그냥 주세요"(주소만), POST="이 내용으로 조회해 주세요"(본문 동봉).
- **요청 본문(body/payload)**: POST에 같이 보내는 내용물. 여기선 조회 조건이 담긴 XML.
- **헤더(header)**: 요청/응답에 붙는 메모(누가·어떤 형식인지 등). 예: `Content-Type`.
- **상태코드(status code)**: 응답 결과 숫자. `200`=성공, `307`=다른 곳으로 보냄, `404`=없음, `500`=서버오류.
- **XHR / AJAX**: 웹페이지가 **화면 갱신 없이** 뒤에서 서버와 주고받는 요청. 개발자도구 Network 탭에서 보임.
- **개발자도구(DevTools)**: 브라우저에서 `F12`. Network 탭에서 사이트가 실제로 어떤 요청을 보내는지 관찰.
- **엔드포인트(endpoint)**: 데이터를 받는 서버 주소(URL). 여기선 KOFIA의 `…/proframeWeb/XMLSERVICES/`.

## 데이터 형식
- **XML**: `<tag>값</tag>` 형태의 데이터 표기. KOFIA 응답 형식.
- **파싱(parsing)**: 받은 텍스트(XML)에서 **원하는 값만 골라 뽑는** 작업.
- **JSON**: `{"key": "value"}` 형태(여기선 안 쓰지만 흔함).

## 저장/DB
- **SQLite**: 파일 하나가 곧 데이터베이스인 가벼운 DB. 설치 불필요(파이썬 내장).
- **테이블/컬럼/행(row)**: 엑셀의 시트/열/행과 같은 개념.
- **PK(기본키, Primary Key)**: 행을 유일하게 구분하는 열(들). 여기선 `(펀드코드, 날짜)`.
- **upsert**: "있으면 갱신(update), 없으면 삽입(insert)". 중복을 막는 핵심 기법.
- **멱등성(idempotent)**: **여러 번 실행해도 결과가 같음**. 같은 날 두 번 돌려도 중복이 안 쌓이는 성질.
- **ER 다이어그램**: 테이블들이 어떤 키로 연결되는지 그린 그림([docs/schema](../docs/schema/README.md)).

## 파이썬/개발
- **모듈(module)**: `.py` 파일 하나. **패키지(package)**: `.py`들을 담은 폴더.
- **함수(function)**: 입력→출력 하는 작은 기계. **순수함수**: 같은 입력이면 항상 같은 출력(부작용 없음).
- **가상환경(venv)**: 프로젝트별로 라이브러리를 따로 담는 상자(다른 프로젝트와 충돌 방지).
- **pip**: 파이썬 라이브러리 설치 도구.
- **리팩터링(refactoring)**: 동작은 그대로 두고 **코드 구조만 깔끔하게** 바꾸기.
- **TDD**: 테스트를 먼저 쓰고 코드를 맞춰 가는 방식.
- **CLI**: 터미널에서 명령어로 실행하는 프로그램(예: `python -m tdf_crawler.run`).

## 클라우드 / 운영 (Part 2)
- **클라우드 VM**: 남의 데이터센터에 빌린 **항상 켜져 있는 리눅스 컴퓨터**. 매일 도는 작업에 적합.
- **SSH**: 내 PC에서 **원격 VM에 안전하게 접속**하는 통로(터미널). 키(비밀번호 대용)로 인증.
- **cron**: 리눅스의 **시간표 비서**. 정해진 시각에 명령을 대신 실행. (예: 매일 08:00 크롤러 실행)
- **crontab**: cron의 시간표 파일. `분 시 일 월 요일 명령` 한 줄로 일정 등록(`crontab -e`/`crontab -l`).
- **타임존(timezone)**: 시간대. cron이 *몇 시*에 도는지는 VM 시간대에 좌우 → `Asia/Seoul`(KST)로 맞춤.
- **데몬(daemon)**: 백그라운드에서 늘 도는 서비스. `cron` 데몬이 켜져 있어야 crontab이 실행됨.
- **무인(unattended) 운영**: 사람이 매번 안 켜도 **자동으로** 도는 것. 멱등성이 있어야 안전.
- **배포(deploy)**: 만든 코드를 **실제 돌아갈 곳(VM)** 에 올려 동작하게 하는 것.

## 이 프로젝트 도메인
- **TDF(Target Date Fund)**: 은퇴 목표연도(예: 2045)에 맞춰 자산배분이 자동 조정되는 펀드.
- **기준가(NAV)**: 펀드 1좌의 가격(원).
- **설정액**: 펀드에 들어온 원본 규모(백만원).
- **순자산**: 펀드가 보유한 자산 총액(백만원).
- **합성총보수(TER)**: 펀드 보유 시 드는 연 비용 비율(%).
- **KOFIA**: 한국금융투자협회. TDF 공시 데이터의 출처(`dis.kofia.or.kr`).
